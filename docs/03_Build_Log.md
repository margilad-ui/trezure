## מה חסום לקלוד מהסשן (מהלגו, עדיין נכון)

- `create_project` ו `pause_project` ב Supabase מה API. עובד דרך הדשבורד בכרום של גילעד אחרי שהוא מתחבר. `apply_migration`. SQL הרסני (drop, revoke). יצירת טבלה עם מדיניות באותה קריאה. כתיבת סודות ב SQL. `create policy` על storage.objects היה חסום בלגו; **ב organizur עבר מ SQL** (16.10).
- רשת ל supabase.co, github.io, cdn.openart.ai, storage.googleapis.com, גם מ `device_bash`. npm ו api.github.com פתוחים. GitHub Actions פתוח לכל דבר: שם מורידים נכסים מ Storage. בדיקות חיות דרך הדפדפן המובנה של אפליקציית Claude, או Claude in Chrome כשכרום של גילעד פתוח.

## מה עובד טוב (לשמר מהלגו)

- `execute_sql` לכל שינוי סכמה, רק הוספות, views במקום טבלאות חדשות עם מדיניות.
- `deploy_edge_function` עם הקובץ המלא.
- `git push` ל main → Pages תוך דקה. `npm run build` ירוק לפני כל push.
- ייבוא קבצים ל Storage דרך פונקציה (`asset_import` מהלגו, יועתק).
- הדפדפן המובנה לבדיקות כשגילעד לא ליד המחשב; Playwright מקומי לצילומי מחשב מדויקים.
- ספר סקירה HTML עם שדות הערות; כפתור "הערות" באתר החי.
- PDF מעוצב: HTML + Playwright `page.pdf` עם @fontsource.
- **צינור נכסים:** OpenArt (`openart_generate_image`, gpt-image-2-5-sunburst, image2image עם רפרנס) → `net.http_post` מ SQL לפונקציית `assets` (`{url, path, key:'white'}`) → Storage `brand` (ומסירה רקע לבן ל `-clean.png`). צפייה בתוצאות: קישורי Storage בכרום של גילעד (`browser_batch` עם navigate + screenshot).
- **תוויות:** `03_Labels/build_labels.py` + `render.mjs`. HTML ב mm, Playwright ב deviceScaleFactor 203/96, PNG בדיוק בגודל.
- **לוגו:** `02_Brand/build_logo.py` (fontTools על Poppins מ @fontsource + זרוע z כנתיב SVG). PNG דרך Playwright.
- **ElevenLabs Player MCP:** `generate_sound_effect`, `generate_tts` שומרים ב `Downloads\ElevenLabs`; העתקה לתיקייה ב `device_bash`.
- **Shopify MCP** `generate-domain-names` לבדיקת דומיינים.
