# TREZURE · README

**עודכן:** 17 באוקטובר 2026, 12:45. השם הסופי: **TREZURE** (טרז'ר). שם הפרויקט הטכני (תיקייה, Supabase) נשאר `organizur` / THE ORGINAIZUR; הריפו ייקרא `trezure`. מוצר של ZUR, Creative Product House של גילעד צור. THINK.BUILD.IGNITE.

## מה זה

מערכת תפעול לכל הציוד שיש לגילעד בבית, במשרד ובמחסן: ציוד לפעילויות וסדנאות, ציוד יצירה, Cricut (מכונה, להבים, ויניל, HTV, חומרים), סובלימציה (מדפסת, דיו, נייר, מוצרים ריקים), פאזלים, מתנות, ציוד משרדי, משחקי חברה, משחקי הרכבה ועוד. בשלב שני: הנגרייה (כלים, פרזול, בורגייה, חומרים) באותה מערכת, כאתר נוסף.

המטרה: **תפעול, לא תיעוד ולא מכירה.** לדעת מה יש, כמה, איפה, במצב מה. למצוא בשניות. לא לקנות שוב. בהמשך: לארוז לפעילות ולהחזיר, ערכות, שיתוף עם משתמשים נוספים והרשאות.

הכוונה: מוצר שאפשר למכור. UX, UI ויופי ברמה של "פרימיום של הפרימיום". דמות (OKI, תמנון) שהיא הקול של ה AI.

## ההבדל מהפרויקט הקודם (BRICK Shop)

בלגו היה קטלוג (Brickset) שמילא הכל ממספר הסט. כאן אין קטלוג, ולרוב אין ברקוד. לכן **התמונה היא הקטלוג**: מצלמים מהר בטלפון, ו AI קורא מהתמונה שם, מותג, קטגוריה ושדות, ומציע. גילעד רק מאשר או מתקן, במחשב, בקבוצות.
